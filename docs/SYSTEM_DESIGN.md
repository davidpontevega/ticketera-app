## Mantenimiento

Cuando una spec nueva define o cambia arquitectura, modelo de datos o autenticacion, el agente `spec` agrega o
actualiza la fila correspondiente aqui mismo (una fila, sin copiar contratos). Si un area queda cubierta por mas de
una spec con el tiempo, se referencia la mas reciente/vigente, no se listan todas.
